# 新主轴下的局部截面主材验证

日期：2026-10-10。分支：`feat/recognition-mainline`。对比基线：`2750c1c`，上轮 `gkz-fixed/` 报告。设计见 [局部截面主材](../design/2026-10-10-local-section-main-material.md)。

## 根因与实现边界

归因属于特征消费与证据优先级问题：导出器已有截面零件身份，但旧筛选以整根组合体的轴长限制单块分段壁板；聚合截面计数又把密集附属区、端部单板当成主体截面冲突。直接删除所有筛选的试验曾在单例多收 186 个种子，不能作为修复。

- BOX：闭合空腔、核心零件角色、主件参与形成局部证据；允许明确标注 `dense_attachment_zone` 的截面，未知异常原因不进入新证明路径。既有壁板延续分组继续补全分段。
- H：同站位明确不同的上翼缘、腹板、下翼缘 ID 与有效切片；不同站位重复且角色一致，形成完整三板集合，再按共用核心板或实际 Weld/Contact 关系关联主件。重复站位不算纵向证据；冲突站位、缺切片、角色矛盾及不相连的另一套 H 不纳入新确认集合。
- 明确非板主件不能由附属板重新定义。规则不引用构件号、零件号或项目名进行分类。
- 类型汇总只消解同主体零件的端部单板或密集区异常计数；正常有效的不同截面即使共用 ID 仍保留 UNKNOWN，独立核心冲突同样保留。
- 已确认局部 H 的段范围来自板件及站位，不扩大至整轴长度。复杂度与零件表共用局部证据。

完整局部证据确认的种子不受旧 BOX 800mm/45%、H 1800mm/50% 及截面切长占比门槛否决；没有新增毫米或整轴占比门槛。**证据不足的旧兼容路径仍保留原筛选条件，既有延续扩展也保留原几何约束，本轮并未删除全部历史阈值。** 新选择集中局部 BOX 路径 27 个、局部 H 路径 208 个，其余 744 个还包括原生型钢等类型，不能都理解成依赖旧阈值。

## 抽象复盘

最初遗漏源于把组合体的整体尺度作为分段零件的准入条件，再把局部计数提升为整个主体的类型；新主轴更准确反而放大了这类粒度错配。

适用于分段、拼装和多尺度识别的检查方法：先区分整体轴线、局部截面、零件身份和报告汇总；以可追踪的局部完整证据确认成员，再检查连接与真实冲突。长度比例只能辅助缺证据的候选筛选，不能推翻已有完整证据。下游同时依赖类型、主材 ID、附件边界和派生工序，单看类型命中率不够。

防复发清单：轴长变化而局部几何不变的测试；短完整段与长附件的正负例；不同实例身份一致性；类型与主材集合的跨表验证；牛腿单元 ID 回归；所有字段差异限定在可解释范围；人工验收和自动验证明确区分。本轮 293 项测试、979 装配字段比较及 32 个牛腿身份回归提供了已验证证据。Memory MCP 不可用，复用结论保存在本记录。
