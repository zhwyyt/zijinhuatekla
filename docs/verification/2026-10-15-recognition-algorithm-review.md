## 功能与正式入口

CLI `export-excel` / GUI 共用 `reports/combined.py:export_combined_excel`，每个装配读取同一实例的 bundle 与 member 快照，分别生成构件角色、构件复杂度、零件特征三张表。

| 层次 | 回答的问题 | 当前主要方法 |
|---|---|---|
| 实例身份 | 这是哪一个实体装配/零件 | AssemblyId / PartId；位置号用于报告和精准清单核对 |
| 构件主轴与姿态 | 整体向哪里延伸，是否折线 | 导出器方向分组、贴合集合、跨度主轴；角色读折线首尾弦 |
| 构件结构角色 | 柱、梁、支撑、埋件等职能 | 姿态、外部连接、装配内部几何的规则断言 |
| 主材截面与主材集合 | BOX、H、十字等；哪些板组成主体 | 局部截面拓扑、核心板身份、跨站位重复和连接连续性 |
| 零件空间/功能关系 | 内部板、外部附件、牛腿成员、垫板等 | 局部投影、拓扑关系、附属簇与专用规则 |
| 加工事实和车间分类 | 孔、切割、坡口、倒角、折弯、方块/异形等 | 导出操作、solid 证据、几何分析与既有车间口径 |
| 清单校对 | 编号、数量、规格、制造范围是否一致 | 独立 compare / Data Quality Gate，不能反向改识别结果 |

这些维度不可互相替代：BOX 不等于柱，内腔零件不等于内隔板，焊到主体不等于牛腿，带孔矩形外轮廓与车间“异形”可以同时成立。

正式零件特征表输出主材标记、BOX 内外、加工字段和焊接垫板，没有输出完整的通用零件角色列。旧 `emit-excel` / `analyze` 路径仍调用 `part_roles.py:infer_role`，包含名称、编号系列和尺寸回退，不能与正式特征表视为同一判定链。

## 已有方法中值得保留的部分

1. 身份、几何、结构角色、加工分类、清单核对已经有基本分层；精确编号匹配不被几何近似替代。
2. 主轴由同一导出实现提供；Python 不再从最长零件重复推轴。主轴、折线、主材和结构职能分别表达有必要。
3. 新局部截面方法优先于整轴长度门槛：BOX 用空腔与核心壁板身份，H 用不同站位完整三板切片、角色一致性和主体连接。
4. 保留 UNKNOWN、冲突与连接复核候选，不要求所有对象强行赋值。
5. 已有同号多实例、短分段、附件排除和牛腿身份回归，适合作为继续讨论和改进的基线。

历史验证记录中的 302 tests OK、979/979/7086 行、16998 件、0 运行失败不是本轮新跑的完整回归。0 运行失败不代表全部标签正确。8 个主材类型变更和 74 行主材标记仍保留原记录的人工复核边界。

## 需要讨论的算法边界

### 1. 事实、业务推断与最终证据混合

`member_structural_role.py:context_from_external_links` 当前把相邻对象姿态近似为角色：竖直对应柱、水平对应梁。倾斜主段直接返回空上下文；屋面、成排布置、开间三角、轨道等字段没有从这里自动构造。定义了 15 类不等于真实导出路径已经能自动识别全部 15 类。

`classify_body_bracket_assembly` 对单根倾斜紧凑杆件按已接受口径判支撑，但通过设置 `paired_with_brace=True` 和两端 `gusset` 触发通用规则。最小复现：单根 100×100×3000 杆，45° 倾斜，无关系、无外部链接，返回 BRACE，证据包含 `end.gusset`、`pair.brace`。

这是本轮确认的证据表达问题；不把已接受的“单斜杆判支撑”业务约定擅自撤销。建议保留独立规则和 `single_inclined_compact_bar` 几何证据，标明推断来源，不把未观测的节点板/成对关系写成事实。本次真实 979 装配没有 BRACE 输出，这一边界复现不等于本批存在对应误判。

建议采用“必要事实校验 → 候选角色 → 排除冲突 → 输出结论/待复核”的顺序。弱名称、方向或尺寸相似不能通过累积分数替代必要连接条件。真实连接、几何接触和近邻候选分别记录。

### 2. 牛腿根部与外伸特征的定义需先修正

`spatial_features.py:_cluster_to_features`：

- `root_contact_ratio = 根部相连零件数 / 簇内零件数`，并非接触面积或接触宽度占比。
- `cantilever_ratio = 垂直轴线的包围跨度 / max(1, 根部相连零件数)`，长度除以件数，不是无量纲外伸比。
- 世界坐标包围盒、质心和整体轴长参与判定，可能受旋转、局部折线和拆板方式影响。

`bracket_classifier.py` 把根部比例不大于 0.45 作为正证据，没有先要求根部连接数大于零。已用两零件簇做匿名复现：无主体根部边、簇内有焊接、存在外部连接、位于主体侧外且非端部，得到 `Bracket`，包含 `ROOT_LOCAL_ATTACHMENT`，missing 为空。

这证明分类器边界允许无根部证据的命中，不证明现场牛腿计数已经错误。历史 32 个 GKZ 实例的数量和单元身份回归应继续保留。

建议先定义牛腿单元为“在某局部主体面上有可追溯根部、向外延伸的承托单元”，再讨论根部长度/面积、出挑长度、末端连接、主脊和附件归属。多根 H 型材按实例拆单元、纯板式按整个连通簇计单元的现行做法，仍可能与真实制造单元不一致。

### 3. 主材局部证明正确，但整体汇总仍较粗

完整局部 H/BOX 证据已经绕开旧长度门槛，兼容路径仍保留 BOX 800 mm / 45%、H 1800 mm / 50% 等条件。不能简单删掉所有门槛：历史试验曾把大量附件收为主体。

建议按局部区间表达主体：区间内截面类别、核心 part IDs、局部轴和证据状态；跨区间按连续性关联。同一位置证据冲突与不同位置真实变截面是两回事。现在整体类型碰到多种有效签名会 UNKNOWN，未来可在有充分分段证据时明确“组合/变截面”，不是放宽冲突门。

质心在内腔可证明位置关系，却不能独立证明整块板完全在内腔，也不能证明其功能为内隔板。贯穿板、跨腔板建议比较截面占据范围和穿越边界，并单列跨界关系。

### 4. 功能角色的专用规则仍存在替代特征

- 焊接垫板：当前窄长、无螺栓孔、焊接到符合宽度条件的母件即可命中；两块母板接缝和坡口目前主要为附加证据。普通窄加劲条与真正背衬的区分需要焊缝根部位置、跨缝关系等证据。
- 楼梯：当前检查两根足够长的倾斜非板件、至少八块尺寸分组一致的短板，没有验证两梯梁彼此平行及踏步空间序列。本轮用两根平面方向相差 90° 的倾斜杆和八块同尺寸板复现 `stair_flight=True`；没有据此认定真实样本误判。
- 主材形态：PolyBeam 对象类型与实际几何折点数分属不同依据，因此可以出现“形态折弯、主轴折点 0”。这已有历史解释，本轮不改。后续如需严格几何表达，应分别保留建模类型、实际轴形和制造成形方式。

专用规则应围绕角色的物理关系补证据，不能仅把阈值改得更复杂。

### 5. 两条零件入口与编号回退

正式 `reports/member_complexity.py:is_embedded_member_id` 使用编号包含 `MJ`，零件特征入口复用这个判断；正式构件角色采用锚板、圆杆、焊接、同侧几何判断。

旧 `part_roles.py:infer_role` 还包含 `CP-1`、DB/H/PX/PR 系列、名称和绝对尺寸回退；`pipeline/offline.py` 还有人工 casebank 的主材位置号读取。这些是现存实现，不是本轮新增规则。不能把旧路径的角色输出宣传成完全与编号无关，也不能将这些旧路径问题不加区分地归到正式三表。

建议所有入口最终消费一份装配识别结果；名称/编号约定如果要保留，单列项目映射来源，不能冒充几何事实。对所有硬编码不能无依据一删了之，需要实际样本和已接受业务口径迁移。

### 6. 加工事实、工艺建议与同号汇总

当前已有真实切割相交证明和坡口来源检查；应保留这些强证据。部分兼容路径仍通过孔/切割计数差值、OBB 恢复矩形、建模类型等推断最终类别。缺字段常归零，可能混同“没有”和“未观测”。

建议加工特征保留实体/操作 ID、所属面/边、参数、来源和状态；同一孔由 Bolt 与 solid 两个来源发现时去重，不以简单计数相减替代关联。几何上的孔不天然等于必须钻孔，实际工艺应明确来自车间策略；当前已接受策略先保持。

带孔矩形→异形、主材→异形主材是已确认的车间分类，不应在讨论中当成外轮廓算法错误。建议底层同时保存“矩形外轮廓 + 孔 + 主材身份”，车间标签由独立映射生成。

正式零件表按装配内 `partPosition` 汇总，工序/形状不一致会 UNKNOWN，但规格/长度/材质取首项，主材取一个非空值，内部/垫板等用 any 合并。建议先验证同号身份属性与加工特征一致，再汇总数量，明确何时拆行或进入冲突复核。几何一致性只做同号质量校验，不允许跨号自动匹配。

## 建议的讨论顺序与验收指标

1. 明确每个字段的定义、必要事实、允许推断和 UNKNOWN 条件；先区分缺数据、证据冲突、未覆盖类型。
2. 以当前样本把未知分桶，优先解决有连接但不能解释的端点/局部段上下文；同步讨论牛腿根部和单元边界。
3. 统一局部截面与零件关系结果，再统一正式/兼容入口；最后根据人工标注调整阈值或评分。

可先使用现有 JSON 和显式邻接表，不需要为此引入图数据库或学习模型。大模型可以辅助解释和复核，不能替代几何与连接事实。

验证至少分别报告：已确认结果准确率、覆盖率、各类误判/漏判、未知原因、主材集合准确性、牛腿单元身份与数量、加工特征实体级差异。需要独立人工标注和跨项目留出样本；同号实例不要随机分散到标定与验收两侧造成泄漏。

不变性/反例重点：改编号不改几何结论；同几何换实例不串数据；保持重力方向的平移和绕竖轴旋转不改角色；整体坐标系变换须同时变换重力和参考轴；拆板/合板不应无故改变牛腿个数；去掉连接后不得仍输出已观测连接证据；延长别的构件段不应否决局部完整主材证据；真实冲突保留待复核。
