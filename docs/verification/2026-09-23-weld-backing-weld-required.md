# 2026-09-23 焊接垫板必须存在焊缝关系

## 修正原因

`T3-P-2047` 被误判为焊接垫板。其真实证据只有：

- 窄长板几何：`PL16`，OBB 约 `33.84 x 300 x 16`。
- 无 `weldDetails`。
- 与 `T3-P-4312`、`T3-P-2048`、`T3-P-4506` 只有包围盒 `Contact`。
- 主板剖口为 0。

旧规则的“窄长板 + 接触两个非窄条板”或“接触有剖口主板”作为独立触发条件过宽，会把幕墙附属窄条、连接条等误判为焊接垫板。

## 新口径

窄长板必须先命中 Tekla 焊缝关系（`relationships.edgeType=Weld` 或零件 `weldDetails`），才允许进入焊接垫板判定。

- 有焊缝关系：继续叠加接触、两板接缝、主板剖口、焊缝尺寸等证据。
- 无焊缝关系：`Contact`、包围盒贴近和主板剖口只能作为辅助证据，不得单独命中。
