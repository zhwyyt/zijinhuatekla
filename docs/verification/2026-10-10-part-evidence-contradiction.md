# T3-P-2219 证据矛盾调查

## 请求与范围

用户询问 `标准矩形外轮廓` 与 `主板非标准矩形` 为什么同时出现。本轮只核对来源和因果，不改既有形状分类口径；Qt6 打包相关未提交改动保留，不混入本次调查提交。

## 已验证事实

数据源为 `cache/selected-mainline-20261010-105609`，报告为 `outputs/main-material-axis-20261010/delivery/徐汇T3_当前选择集.xlsx`。精确位置号命中 1 个实例：构件 `T3-5HXZ-3`、装配 ID `70557226`、零件 ID `70557223`、零件号 `T3-P-2219`。

规格 PL40*600、长度 5995、厚度 40，runtimeType=Beam。归一化后轮廓顶点 4、凹角 0、螺栓孔特征计数 3、holeLikeFeatureCount=3、有效布尔切割 1、板边剖口 1、平面倒角 0。此处计数是导出特征字段，不据此推定现场实际孔个数。

当前轮廓检查结果为 RECTANGLE，证据 `标准矩形外轮廓`。报告主材=是、主材说明=一字板、工序=下料+下料钻孔、形状=异形主材、剖口=是、倒角/割孔/洞口=否、螺栓孔=是。精确复现用户报告的全部五条证据，排除同号多实例合并导致的矛盾。

## 证据血缘与根因

1. `geom/chamfer.py::classify_plan_outline` 对投影后的四角轮廓检查矩形，输出 `标准矩形外轮廓`。这是当前导出轮廓的判断，不等同于新增人工几何验收。
2. `geom/shop.py::classify_shop_shape` 在 `bolt_hole_count > 0` 时直接把变量 `outline` 改为 IRREGULAR，保留原矩形证据。
3. 随后主材且 IRREGULAR 的分支统一追加 `主板非标准矩形`，将“按既有含孔规则归入异形”错误解释为“外轮廓非矩形”。板边剖口在此函数只追加证据，并不触发该分类变化。
4. `classify_shop_process` 扣除已归属剖口/倒角的切割，孔类特征减去螺栓孔后无额外洞口，因此 openings=False。代码此时写 `平板无孔`，随后又因 bolt_hole_count>0 追加 `螺栓孔`。本例实际上是“无额外非螺栓孔洞口”，并非没有孔。
5. `reports/part_feature_excel.py` 将工序证据与形状证据直接拼接，没有进行维度区分或语义一致性检查。

归因是证据语义和分类维度混用，现有特征足以说明本例；不是主轴算法、零件编号或新增类型导致。`tests/test_shop_geometry.py` 既有测试明确要求“带孔矩形板→异形”，所以不能把本次询问自动当作变更该业务口径的授权。

## 建议修正与验收要求（尚未实施）

外轮廓、孔/切割/剖口特征、主材身份、加工分类应分别表达。保留现有加工分类时，本例可以描述为“矩形外轮廓；有螺栓孔；板边剖口；主材；按含孔规则归入异形主材”，不能继续写 `主板非标准矩形` 或 `平板无孔`。若要让“形状分类”仅按外轮廓判断，则应单独确认规则，并更新带孔矩形的既有回归。

Acceptance Criteria：孔不能作为外轮廓非矩形的证据；有螺栓孔时不输出笼统无孔；真实非矩形、倒角、洞口和主材身份仍可追溯；不按零件号写特例。

Verification Plan：增加矩形+螺栓孔+主材+剖口组合的证据一致性断言，以及非矩形主材、非主材、无孔板、割孔板反例；重跑本例及三表字段对比，明确仅证据变化还是分类变化。

本轮已完成精确实例提取、归一化字段检查、轮廓函数运行及现有 Excel 逐字段读取；未修改或重跑识别规则、未重新打包 exe。详细本地数据保存在忽略目录 `outputs/part-evidence-20261010/T3-P-2219-source.json` 和 `T3-P-2219-report.json`，不提交业务原始数据。

可迁移教训：派生分类不能反过来冒充原始几何事实；一个变量同时承载轮廓类型和加工分类，会使正确的局部证据组合成错误解释。测试不仅要断言标签，还要检查证据能否支持标签、肯定与否定是否处于同一维度。本例既有测试覆盖带孔矩形的分类，却没有检查证据互斥，因而漏掉此问题。下游依赖证据理解加工原因，说明一致性属于交付正确性的一部分。
