# 2026-09-20 焊接垫板关系识别与工序口径

## 变更

1. 焊接垫板不再看零件名称。分类器只用窄长板几何、Weld/Contact 邻接、焊缝几何（环绕/车间/角焊缝尺寸/从件）和主板剖口。
2. 识别 Excel 的工序不再默认「不下」。只有零件 `customProperties`/`工序` 明确写了「不下」才输出「不下」。其余由下料、割孔、钻孔、折弯组合：
   - 工序1：下料 或 下料割孔
   - 工序2：下料折弯 和/或 下料钻孔

## 失败案例 / 最小复现

- 名称是「衬垫板」但无 Weld/Contact：不得标焊接垫板。
- 窄板焊到 HI/BH 型钢，或贴在两块主板接缝：应标焊接垫板，即使名称是「板」「连接板」「衬条」。
- 电渣焊块 PL25*50、圆杆 D8：不是焊接垫板。
- 轧制型钢无零件信息写「不下」：工序为空，不得填「不下」。

## 期望标签

- 角色：`焊接垫板`
- 工序：`工序1：下料` / `工序1：下料割孔` / `工序1：下料；工序2：下料钻孔` / `工序1：下料；工序2：下料折弯`；仅声明「不下」时为 `不下`

## 证据字段

- 窄长垫板几何
- 焊缝连到主板/型钢、焊缝环绕接缝、角焊缝尺寸、车间焊、作为焊缝从件
- 与主板接触、贴在两块主板接缝、主板有板边剖口
- 工序：平板无孔 / 下料割孔 / 洞口 / 螺栓孔 / 板件出平面/折弯体 / 零件信息写明不下
