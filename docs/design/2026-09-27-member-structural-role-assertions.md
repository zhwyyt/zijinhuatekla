# 构件结构角色几何断言

实验分支：`experiment/part-role-geometry-assertions`

2026-10-10：用户确认本实验最后成果已经人工验收。现已进入 `feat/recognition-mainline` 正式识别收尾，入口与验收见 `2026-10-10-recognition-mainline.md`。本文件定义构件结构职能，不替代零件角色或主材截面口径。

## 边界

一个装配只给一个主角色。箱型、H 型、十字、圆管这些截面名称，以及它是第几节柱，都不进入本分类。格构柱、桁架梁进入组成子类。

三层各答一个问题：

- 构件角色：整根构件把力送到哪里。
- 截面形态：主材长什么样。现有构件复杂度报告继续负责这一层。
- 零件角色：构件内部每一块板是什么。牛腿、内隔板、缀板都留在零件层。

构件编号中的 `GKZ`、`GL`、`GKL`、`MJ` 只可写入备注，不得作为命中条件。

## 主角色

主角色 15 个，外加未知。

| 代码 | 名称 | 职能 |
|---|---|---|
| `COLUMN` | 柱 | 两端连线竖直，侧面接楼面梁或墙梁。下端落到基础、柱脚底板或下一节柱；这些对象不在本次模型里时，由竖直柱段和已有的水平连接推测 |
| `INCLINED_COLUMN` | 斜柱 | 两端连线倾斜，下端仍往下传，上端继续往上接，梁从侧面接进来 |
| `BEAM` | 梁 | 轴线水平，两端被柱、梁、牛腿或埋件托住，沿跨度把重力送到两端 |
| `INCLINED_BEAM` | 斜梁 | 轴线倾斜，两端被托住，构件躺在屋面或坡道平面里，上面再接檩条或次梁 |
| `CRANE_BEAM` | 吊车梁 | 轴线水平，两端落在柱牛腿上，上翼缘带连续的轨道或制动连接 |
| `PURLIN` | 檩条 | 成排、平行、间距小，搁在斜梁或屋架上翼缘上 |
| `GIRT` | 墙梁 | 轴线水平，接在柱的侧面，服务墙面，上面不搁楼面次梁 |
| `BRACE` | 支撑 | 轴线倾斜，两端通过节点板连接，所在开间里还有另一根斜杆，两根一起把开间分成三角 |
| `HORIZONTAL_BRACE` | 水平支撑 | 轴线水平，但在平面上斜穿开间，两端用节点板连接，上面不搁次梁 |
| `KNEE_BRACE` | 隅撑 | 短斜杆，一端在梁的受压翼缘附近，另一端接到檩条或水平支撑 |
| `TIE` | 系杆 | 沿房屋纵向布置，连接相邻屋架或柱列，两端铰在节点上，自身不承担楼面跨度 |
| `TRUSS` | 桁架 | 一个装配里同时能分出上弦、下弦和腹杆，对外只在支座处连接 |
| `EMBED` | 埋件 | 由锚板和同侧锚筋组成，自身没有跨度轴线 |
| `STAIR` | 楼梯 | 两根最长的非板件是倾斜梯梁，并有至少八块同一尺寸的较短板 |
| `STAIR_LANDING` | 休息平台 | 一块水平花纹钢板，其余零件都是同一侧的等边角钢 |
| `UNKNOWN` | 未知 | 证据不足，或两条规则同时成立且互相排除 |

## 判定顺序

先看整件，再看轴线，最后看两端和侧向连进来的对象。

1. 装配内部能分出上弦、下弦、腹杆，对外只在支座连接，定为桁架。
2. 只有锚板和同侧锚筋，定为埋件。
3. 两根最长的非板件是倾斜梯梁，并有至少八块同一尺寸的较短板，定为楼梯。
4. 休息平台花纹钢板单独判定，规则号 `MR-LANDING-001`。材质等级含“花纹”；板件法向与竖直方向夹角在 10° 以内；平面两个方向都不小于 1000 mm，厚度不大于 16 mm。其余零件全部是等边角钢：两肢尺寸比不小于 0.85，肢宽在 20 mm 到 100 mm，长度至少是肢宽的 2 倍。角钢不少于 4 根，质心都在板的同一侧，到板心的距离在 1 mm 到 80 mm。命中的那块板就是休息平台花纹钢板，整根构件角色为休息平台。零件名称和构件编号不参与。
5. 两端连线与竖直方向夹角在容差以内，进入柱。下端在基础、下一节柱或埋件连接面，侧面接楼面梁，子类为框架柱，规则 `MR-COL-001`。下端这些对象不在本次模型里时，仍可定为框架柱，规则 `MR-COL-003`：已经有焊缝或螺栓连到水平构件，构件不是单块板，轴线长度至少达到零件截面中等尺寸的 4 倍。证据写 `end.lower.outside_model`，不把缺席的下一节写成已经存在的对接。上方节段不参与。没有水平连接时仍为未知。构件编号不参与。侧面主要接墙梁、上端不接楼面主梁，子类为抗风柱。
6. 两端连线与水平方向夹角在容差以内，按下面的顺序归位：平面斜穿开间且两端为节点板、上面不搁次梁的是水平支撑；沿纵向连接屋架或柱列、不承楼面、也不斜穿开间的是系杆；成排搁在屋面梁上的是檩条；接在柱侧、服务墙面的是墙梁；两端在牛腿上且上翼缘有轨道或制动连接的是吊车梁；两端都被托住，或一端被托住、另一端自由的，是梁。
7. 两端连线倾斜：躺在屋面或坡道平面里、上面接檩条或次梁的是斜梁；两端是节点板、并与另一根斜杆成对的是支撑；一端在梁受压翼缘、另一端在檩条或水平支撑上的短杆是隅撑；下端继续往下传、侧面接梁的是斜柱。

竖向和水平容差均为 10°。折弯构件先取两端连线判断姿态，相邻轴线段方向变化大于 5° 时记折点。中间折点不改变主角色，只把轴线形态写成折线。

以下组合同时成立时停在未知，不按顺序硬取一条：

- 平面斜穿开间，同时上面搁楼面次梁。
- 平面斜穿开间，同时被记为纵向系杆。
- 躺在屋面里并支承檩条，同时两端节点板成对组成支撑。

任一必要连接事实没有观测到，也停在未知。不得用构件编号补全。

## 子类

子类是主角色上的属性，分两栏。两栏可以同时有值。

职能子类回答它在结构里处在什么位置。

| 主角色 | 职能子类 | 条件 |
|---|---|---|
| 柱 | 框架柱、抗风柱 | 侧面接楼面梁，或主要接墙梁 |
| 梁 | 框梁、次梁、悬挑梁 | 两端落在柱上、两端落在梁上、一端没有支承 |
| 支撑 | 交叉、人字、单斜、K 形 | 同一个开间里斜杆的布置，由输入事实给出 |
| 支撑 | 柱间、屋面 | 斜杆所在平面，由输入事实给出 |

组成子类回答整根构件怎样组成。箱型、H 型、十字、圆管仍记在截面形态里，不写入这一栏。

| 主角色 | 组成子类 | 条件 |
|---|---|---|
| 柱 | 格构柱 | 至少两根分开的纵向弦杆，弦杆之间有缀条或缀板，整根按柱出厂 |
| 梁 | 桁架梁 | 同一个装配里能分出上弦、下弦和腹杆，整根按梁出厂，两端有梁的支承 |
| 桁架 |  | 主角色已经是桁架。对外只在支座连接、自己不作为一根梁或一根柱出厂 |

格构柱的主角色仍是柱，可以同时是框架柱。桁架梁的主角色仍是梁，可以同时是框梁或次梁。独立桁架继续用主角色 `TRUSS`，不再写成梁的子类。缀条、缀板、弦杆、腹杆留在零件角色。

这两项组成子类当前只定义口径。自动分类还没有对应的几何规则，输出里先留空。

## 本实验实现的事实来源

轴线按 `docs/design/2026-09-29-aligned-span-member-axis.md` 写出。member JSON 的 `GuidePolyline`、`AxisSegments` 和 `Member.MainAxis` 用来证明姿态和折点。`MainAxis` 是主段；折线时 `AxisSegments` 带第二段。姿态优先用引导折线的首尾点，因此折线构件的姿态可以和主段方向不同。

导出器版本 `xingcai-runner-body-bracket-0.3.3-aligned-span-axis`。装配 `metadata` 仍追加 `externalConnectionEvidence`，原有字段保留。每条 link 记录本构件零件、对方零件、对方装配、焊缝或螺栓、车间或现场、连接落在本构件轴线的 `start`/`end`/`middle`，以及对方主材轴线方向和姿态。内部焊缝、螺栓、接触仍留在原来的 `relationships`。`cache/external-links-20260928` 仍是接入前的轴线。

这份证据能支持柱侧面接梁、梁两端落在柱上、斜柱继续往下传。开间斜穿、成对支撑、檩条成排、轨道和制动、屋面平面仍没有几何事实，这些角色继续停在未知。

在这份追加字段进入选择集之前，实验分类器仍把两类事实分开：

- 轴线断言从 member JSON 计算。优先使用引导折线的首尾点，其次使用轴线段首尾点，最后才使用主轴方向。
- 连接事实由 `StructuralContext` 显式输入。字段只表示已经观测到的几何关系，不读取零件名称和构件编号。

没有连接上下文且自身几何不足以证明角色时，输出保留轴线姿态，角色保持未知。分类函数放在 `classifiers/member_structural_role.py`；2026-10-10 起接入离线流水线、CLI、GUI 和正式 Excel 的构件角色表，原实验单参数调用继续兼容。

## 输出

每根构件一条断言：

- `role`、`role_label`、`subtype`
- `pose`：`vertical`、`horizontal`、`inclined`、`unknown`
- `axis_form`：直线、折线、未知
- `bend_count`
- `confidence`
- `evidence_codes`
- `rule_id`

## 缺失连接只进复核

模型里没有焊缝、螺栓或贴合时，距离不提升为连接，也不改变两端的构件角色。

支撑杆仍由自身几何判定：一根倾斜的紧凑杆件就是支撑。支撑节点和牛腿仍要有连接才赋值，没有连接就保持未知。

同时满足下面三条时，写一条 `MODEL_CONNECTION_MISSING` 复核候选：

- 一端是上述支撑杆。
- 另一端是带板件、自身轴线不超过 2000 mm 的装配。
- 支撑杆端点到该短装配轴线的距离不超过 250 mm，且两边的 `externalConnectionEvidence` 都没有焊缝或螺栓。

候选只记录两端装配、间隙和“模型中没有焊缝或螺栓”。人确认之后才可以写成连接。250 mm 以外的邻近杆件，包括约 700 mm 外的圆管和 300 到 700 mm 的檩条，不进入这张候选。

## 验收

- 15 个主角色各有一条合成事实可以命中，未知和三类冲突也有对应用例。休息平台另有花纹板几何用例。
- 竖向或水平的构件编号即使写成 `GKZ`、`GL`、`MJ`，没有连接事实时仍为未知。
- 两端连线竖直、中间有折点的构件，在柱的连接事实齐全时角色仍是柱，轴线形态为折线。
- 原规则测试保留；正式入口的角色表、折线链、旧缓存提示和装配失败另做集成回归。
