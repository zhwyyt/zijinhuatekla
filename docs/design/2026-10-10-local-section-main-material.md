# 新主轴下按局部截面识别主材

## 问题与范围

用户要求主材识别适配已验收分组跨度主轴，规避无业务依据的长度/占比门槛。基线 `2750c1c`。不重算主轴，不改出图 worktree，不按构件号或旧标签强制命中。

当前证据：4 个 GKZ 的封闭箱体采样与密集附属区的“十字”计数冲突；后者的核心零件实为相邻 BOX 段壁板。GL-199 的端部单板与完整 H 段冲突；GL-99 无聚合 H 签名，但局部 H frame 明确给出上翼缘、腹板、下翼缘及切片。BOX 的 800mm/45%、H 的 1800mm/50% 会否决短分段的真实截面。简单删除筛选实验使附属板大量进入主体，不能采用。

## 设计

- 增加共享的局部截面证据消费：BOX 使用封闭空腔及其核心零件角色，H 使用同一站位上明确、不同的三板 ID 和有效切片。原生非板主件不借用附属板重新定义主体。
- 局部证据必须能对应实际零件和主件；H 在不同站位重复且角色无冲突才证明纵向延续，站位跨度不设毫米下限或整轴覆盖比例。
- 密集附属区标记不一概等同几何无效：已明确空腔及壁板身份的 BOX 证据可以使用，其它异常原因保守保留。
- 完整截面确认的零件不再受旧绝对长度、整轴占比、截面尺寸占比门槛否决。旧证据不完整路径先保留兼容，不整体清空过滤条件；保留的限制及适用范围必须在验证记录中说明。
- 构件类型汇总按主体零件身份判定：仅端部单板签名或 `dense_attachment_zone` 异常计数涉及同一已确认主体时，记录为局部截面变化。正常有效的不同截面即使共用零件 ID 也保留冲突；独立核心零件造成的截面冲突仍 UNKNOWN。
- 复杂度和零件表共用证据，截面类别与主材零件集合一致；牛腿身份与工艺字段必须回归。

## Acceptance Criteria

- 4 个 GKZ 恢复 BOX，具体依赖封闭截面及壁板证据，不依赖编号；GL 的端部/局部 frame 案例有可追踪结果。
- 有完整截面证据的短 BOX 壁板、短 H 分段不会因小于 800/1800mm 或整轴占比小而被排除；改变整轴长度不改变这些主材集合。
- 附属板、重复站位的角色冲突、缺少完整截面、原生型钢主体和真实混合截面负例不被强行确认。
- 16 个 GKZ 牛腿数量及单元身份保持，279 项既有回归有解释地通过；新增测试覆盖短段、缺证据、类型冲突和跨表一致性。
- 全量 979 装配重跑，角色、主轴输入、零件身份/数量和加工特征无意外变化；主材变化逐字段落盘，未人工确认的新增结果明确标示。
